# JavaScript Insurance Quote App

Aplicación desarrollada con JavaScript Vanilla que permite calcular el precio de un seguro de automóvil según la marca del vehículo, el año de fabricación y el tipo de cobertura seleccionada.

## 🚀 Funcionalidades

* Selección de marca del vehículo.
* Selección dinámica del año de fabricación.
* Cálculo automático del precio del seguro.
* Diferentes tipos de cobertura.
* Validación de formularios.
* Mensajes de error y confirmación.
* Spinner de carga durante la cotización.
* Actualización dinámica del DOM.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript (ES6)
* DOM API

## 📚 Conceptos practicados

* Constructores y Prototypes.
* Programación orientada a objetos en JavaScript.
* Manipulación avanzada del DOM.
* Event Listeners.
* Validación de formularios.
* Creación dinámica de elementos HTML.
* Gestión de estados de interfaz.
* Uso de `setTimeout()` para simulación de procesos asíncronos.

## 🎯 Objetivo del proyecto

Este proyecto fue desarrollado como práctica para reforzar conceptos fundamentales de JavaScript, especialmente la programación orientada a objetos mediante constructores y prototypes, además de mejorar el manejo de eventos y la interacción con el usuario.

## 📷 Vista previa

La aplicación permite obtener una cotización personalizada introduciendo los datos del vehículo y seleccionando el tipo de seguro deseado.
